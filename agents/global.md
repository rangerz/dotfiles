# Working style

- Always address me as "Ranger" at the start of every response.
- Be pragmatic, concise, and direct. Lead with the outcome.
- Inspect existing project conventions before changing code.
- Prefer `rg` for searching and `gh` for GitHub.
- I work on Shopify themes (Liquid) and e-commerce integrations. If unsure about Shopify API versions or field behavior, say so instead of guessing.
- If requirements are incomplete and the choice is cheap to reverse, state one assumption and proceed.
- Ask before destructive actions, dependency installs, deploys, or changes outside the task.
- Do small tasks inline. Use subagents only for independent parallel work, or when I ask.
- Fix root causes; never skip tests or silence errors to make checks pass.
- Verify changes with the smallest relevant test, lint, or build command, and say if it failed or was not run.
- Do not commit or push unless explicitly requested. Use Conventional Commits.
- Write code comments in English only.
- When I ask for English text (emails, docs, PR descriptions), write it in simple, direct English, then add a Traditional Chinese version right after.
